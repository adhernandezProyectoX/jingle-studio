# Jingle Studio

Escribí una idea y la app compone una canción o jingle cantado: letra, música y voces, en el género que elijas.

- Música y voces: [ACE-Step 1.5](https://github.com/ace-step/ACE-Step-1.5) (código abierto, MIT), usando su demo gratuito en Hugging Face.
- Sin servidor propio: es una página estática que se publica gratis con GitHub Pages.
- Opcional: un token gratuito de Hugging Face (⚙ Ajustes) da más canciones por día.
